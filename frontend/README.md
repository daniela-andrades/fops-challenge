# Frontend

Este directorio será la aplicación Angular 21.

## Objetivo
- Gestionar CRUD de usuarios, items y órdenes.
- Mostrar estado y porcentaje de completitud.
- Permitir ver trazabilidad de inventario.

## Estructura esperada

```text
frontend/
├── src/

│   │   ├── core/

│   ├── assets/
│   └── styles.scss

├── tsconfig.json
├── Dockerfile
└── README.md
```
